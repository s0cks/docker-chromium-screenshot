A callout highlights a piece of information.

## Attributes

| Name | Type | Default | Description |
|---|---|---|---|
| `tone` | `tone` | `accent` | The tone - or color, of the callout. |
| `mono` | `bool` | `false` | Render the body using monospace text. |

## Example

The body of a callout is written in Markdown.

<Tabs>
  <TabItem label="Markdown">

    `````markdown
    ```callout tone=ink mono=true
    This is a *test*
    ```
    `````

    ---

    `````markdown
    ```callout tone=accent
    This is another *test*
    ```
    `````

  </TabItem>
